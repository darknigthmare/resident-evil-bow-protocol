Une image correspond à un asset ou à une pose. Les PNG sont copiés sans modification depuis les sorties du générateur ; leurs empreintes Git et SHA-256 sont documentées. Les références tierces utilisées pour l'inspection ne sont pas publiées dans ce lot.

Les productions sont des candidats statiques ou des études. La roquette reste une étude faute de référence complète en vol. Les six couches de parallaxe, les animations, les pivots, les contacts, les collisions et l'admission dans le moteur ne sont pas validés. La fidélité géométrique 1:1 n'est pas certifiée.

Les refus de génération et les médias historiques non récupérés sont conservés dans le suivi et ne comptent pas comme des fichiers livrés.
