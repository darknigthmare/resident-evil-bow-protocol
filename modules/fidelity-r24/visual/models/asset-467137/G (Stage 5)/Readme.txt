For model em036, the model labeled emdui is using the texture exported by Tim Tool instead of emdui; emdui could not load the .tim texture. Each individual section was exported from Tim Tool, then combined into one image using GraphicsMagick.

Files are provided from the Pl0 game folder. The Pl0 and Pl1 folders (Leon/Claire scenarios) contain identical files, with very few exceptions; Pl1 files are not included unless specifically noted.

Files labeled emdui were exported using emdui (emd UI) by IntelOrca.
Files labeled TimTool were exported using Tim Tool by scorpion2k81.
Files labeled RE2MV were exported using RE2MV (Resident Evil 2 Model Viewer) by Leo2236.
Files labeled tim2view were exported using tim2view by Lab 313.
