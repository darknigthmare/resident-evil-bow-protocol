DUEL DE CONFINEMENT

Prototype de contact utilisant le moteur CQC. Valeurs et commandes adaptées ; portraits statiques provisoires. Aucun résultat n’est transmis aux opérations et aucune sauvegarde n’est écrite.

A/Q ou ← : gauche · D/→ : droite · W/Z/↑ : saut · S/↓ : accroupi · Espace/Maj : garde · J/K : léger/lourd · M : frappe basse · L + direction : technique · I : prise · U : super · O : utilitaire · X : dash · P : pause · Échap : suspendre. Les dix boutons tactiles correspondent aux dix commandes du sujet. Le modèle ne possède pas encore ses animations originales.

Manette standard : stick/croix = déplacement ; bas = saut ; gauche = léger ; haut = lourd ; droite + direction = technique ; LT = utilitaire ; RT = super ; RB = garde ; clic stick gauche = prise ; clic droit = dash ; croix haut = frappe basse ; Start = pause. Appareils physiques non certifiés. Un bouton maintenu ne répète pas les attaques.
