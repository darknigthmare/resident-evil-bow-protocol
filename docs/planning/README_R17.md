# R17 — G-ACCESS / repères textuels

`BOW_REPERES_COMBAT_R17.xlsx` complète les neuf classeurs existants, sans les remplacer. Cinq onglets : Synthese, Lots_P1, Evenements, QA, Sources. Les quatre formules du tableau de bord indiquent 5 lots techniques, 26 tests locaux réussis, 16 familles d'événements et **0 clôture globale 1:1**.

Les cinq travaux sont la lecture sans audio, le traitement fidèle des faits du moteur, le comportement en replay, le panneau clavier et les budgets sans persistance. Les critères globaux P1 restent EN COURS, notamment le matériel physique, les voix, dessins, sons et sources exacts. Les descriptions de journal ne constituent pas des dialogues officiels.

Le classeur est créé et vérifié avec artifact_tool. Les preuves HTTP et le commit final apparaissent dans le rapport exécuté de la PR ; la feuille QA distingue les tests locaux de leur seconde exécution CI.
