Les 115 lignes de Dossiers décrivent le branchement commun, pas 115 campagnes intégralement rejouées. Les 43 lignes d'exercices correspondent aux sessions comparées avec/sans observation : état, commandes et checkpoint doivent être identiques. Aucun objectif, record ou résultat n'est créé par l'interface textuelle.

Les résultats locaux consignés dans la feuille QA sont distincts des scénarios HTTP exécutés dans le workflow du commit livré. Les fichiers JSON et le manifeste de livraison donnent la preuve finale. L'Excel est produit avec artifact_tool ; les composants XML sont transmis sans changer les cellules ou formules.

Ce lot ne contient aucune correction Hunter Gamma, nouvelle animation, voix ou certification de geste officiel. Lecteurs d'écran physiques, écrans mobiles réels et validation exhaustive de chaque parcours restent ouverts.
