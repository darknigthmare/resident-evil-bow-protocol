# R14 — tâches de décors du plan P1

`BOW_STAGES_BAKER_R14.xlsx` complète les classeurs précédents sans les remplacer. Six onglets : synthèse, 18 lots P1, trois salles, douze composants animés, QA, sources/limites. Créé avec artifact_tool ; ses 23 composants XML sont conservés à l'octet près par le transport vérifié.

Les identifiants sont `S-{stage}-GEO`, `AMB`, `LUX`, `PROP`, `SEQ`, `QA` pour baker_garage_2017, guest_house_attic_2017 et testing_area_2017. Les trois géométries exactes demeurent OUVERTES. Les quinze autres lignes sont EN COURS, avec une adaptation livrée ou une vérification technique, et leurs critères restants. Aucun lot de fidélité 1:1 globale n'est fermé par ce classeur.

Les vingt nouveaux groupes de tests natifs ont réussi sur le candidat 37af62dc87bee391222fb6ed8d90d98111a34bae. Le workflow 39366770424 contient la chaîne complète de 457 groupes et 54 scénarios HTTP, dont huit R14. La validation du classeur et de son téléchargement est relancée séparément avant publication. Les rapports exécutés du commit final font autorité, pas un statut de projet inféré.
