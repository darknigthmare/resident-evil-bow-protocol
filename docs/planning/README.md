## Suivi R8 inclus dans le dépôt

`BOW_PR11_SUIVI_R8.xlsx` : 4 onglets (pilotage, lots, références primaires consultées, 19 tests). Il complète le classeur maître sans transformer des raccords techniques en dessins finalisés.

R8 raccorde le rendu partagé aux phases existantes : entrée, victoire/défaite de manche, manche nulle, victoire/défaite de match. L'outro dispose d'un état explicite pour l'atelier, mais sa nouvelle séquence canonique n'est pas produite.

Les lots graphiques par combattant restent ouverts : 692 poses R1 et 692 poses de match à relever et dessiner. Les 3460 commandes du build restent distinctes d'un répertoire officiel exhaustif. Les 43 exercices contextuels ne sont pas promus dans les campagnes.
