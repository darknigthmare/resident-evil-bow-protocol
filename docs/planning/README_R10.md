# Suivi R10 (local)

Le classeur `BOW_PR11_SUIVI_R10.xlsx` complète les classeurs R8 et R9 inchangés. Il ne remplace pas le P1 détaillé. Ses cinq onglets distinguent la synthèse, les lots locaux, les 115 gabarits, les références et les 40 contrôles/scénarios spécifiques de R10.

`VALIDÉ LOCAL` signifie que le chemin de code a passé les tests disponibles dans cette livraison. Cela ne signifie ni `publié sur GitHub`, ni `dessiné 1:1`, ni `lot P1 fermé`. Les lignes `F-{UID}-FIN` restent des lots de production plus larges que le filtre technique.

Les chiffres du tableau de bord sont calculés à partir des tables, pas saisis comme des résultats artificiels. Le nombre de combinaisons permises provient du même module que la garde du moteur. Les dimensions sont celles du prototype, pas des mesures officielles.

Voir `docs/DELIVERY_R10_SCOPE.md`, `docs/DELIVERY_R10_TESTS.json` et `qa-delivery-r10/BROWSER_R10_RESULTS.json` pour les limites de test, dont le blocage de la navigation HTTP et l’absence de nouvelle CI GitHub.
