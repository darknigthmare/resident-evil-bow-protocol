# R16 — G-AUDIO dans les duels isolés

`BOW_DUELS_AUDIO_R16.xlsx` complète le plan P1/R8–R15. Cinq onglets : Synthese, Lots_P1, Evenements, QA, Sources. Quatre formules de tableau de bord contrôlées : cinq lots techniques, 25 tests locaux, 15 règles sonores, zéro lot global 1:1 terminé.

Ce suivi décrit l'intégration de la banque originale existante à l'annexe. Il ne crée ni nouvelle voix, ni cri officiel, ni capacité de combat. Les lignes globales G-AUDIO/G-REPLAYS/G-ACCESS/G-PERF/G-RECETTE restent ouvertes ou en cours ; seule leur partie décrite dans R16 est traitée.

Le téléchargement dans catalog-duel.html est comparé au XLSX versionné dans le test HTTP. Les JSON exécutés et le workflow du commit final fournissent la validation CI distincte de l'état de préparation du classeur.
