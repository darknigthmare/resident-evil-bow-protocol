# R15 — son des trois salles Baker

`BOW_AMBIANCES_BAKER_R15.xlsx` complète les plans précédents, avec cinq onglets et quatre formules. Les trois lignes `S-{stage}-AMB` de R14 restent EN COURS, car une composition sonore originale ne prouve pas l’acoustique ou les sons précis de RE7.

Neuf couches réparties sur trois salles sont produites en PCM stéréo, intégrées au son existant du Versus principal/Dossiers et écoutables dans l’atelier. Le téléchargement de ce fichier, les commandes de son et le fonctionnement du Web Audio sont testés en CI. Les 21 groupes indiqués dans le classeur proviennent de l’exécution locale ; les rapports exécutés du commit final documentent la validation HTTP et la suite complète.

Les WAV de preuve sont exportés depuis le même code, sans enregistrement tiers. Leur analyse numérique et le rendu OfflineAudioContext ne sont pas une recette perceptive sur matériel physique. Les sources techniques figurent dans l’onglet Sources. Aucun lot global du P1 fermé ; anciens XLSX conservés.
