# R34 — cinq corps réexaminés après le premier gel

Les cinq sorties explicitement rouvertes sont scellées : **5 corps réellement générés, 3 poses droites proposées au combat et 2 études entières non admises**, sans refus ni état en attente.

| UID | Résultat |
| --- | --- |
| revillage-soldat-jet | Pose droite en vol stationnaire, deux forets, bottes et propulseurs entiers. |
| re2-large-roach | Pose droite complète ; antennes et pattes vérifiées contre le catalogue1998. |
| re2-g-fourth-form | Pose droite à six membres complète, fondée sur l’artwork compatible avec le catalogue1998. |
| revillage-urias | Corps et marteau entiers ; torse encore frontal malgré la tête droite, donc étude non assignée. |
| rerev-sea-creeper | Corps aquatique entier ; présentation encore frontale, donc étude non assignée. Aucune équivalence nativePC/HD2013→3DS2012 n’est supposée. |

Les références étaient déjà présentes : leur qualification initiale « coupée » était trop conservatrice. La réinspection réelle a établi les extrémités visibles, sans inventer de nouveaux pixels sources. Les anciennes décisions HELD sont conservées exactement dans les archives de l’importeur et chaque nouveau fichier reste le PNG brut de l’outil. Dix retours positifs, avec leurs requêtes exactes et leurs versions de correction, sont conservés dans les preuves ; ils ne deviennent pas dix sorties demandées.

La fidélité géométrique1:1, les surfaces cachées et une animation idle originale ne sont pas certifiées.
